# Отель «ЮрЛа», Рыбинск — сайт

Новый сайт отеля (замена hotel.yurla.ru). Статика: HTML, один CSS, один JS, без сборщиков и библиотек.
Визуальная система — по образцу страницы отеля AZIMUT Hotels (палитра, шрифтовая шкала, сетка 1200 px,
линии 1 px, кнопки 48 px без скруглений, движение); тексты, фото и знак — свои, с сайта отеля.

## Страницы

| адрес | что |
|---|---|
| `index.html` | главная: первый экран с бронью, об отеле, рядом с отелем, номера и цены, ресторан и услуги, галерея, вопрос-ответ, контакты |
| `rooms/*.html` | шесть страниц номеров: фото, описание, удобства, цены за сутки, правила заселения |
| `rybinsk.html` | город и достопримечательности рядом |
| `credits.html` | авторы фото |
| `404.html` | страница «такой страницы нет» |
| `Nomera.html`, `Restoran.html`, `Nomera/*.html` … | переадресации со старых адресов hotel.yurla.ru |

## Бронирование

Форма отправляет заявку так же, как старый сайт: `POST /remote.php?f=1&n=<код номера>` с полями
`date_start`, `date_end` (формат `ГГГГ.ММ.ДД`), `vz`, `det`, `mail`, `phone`, `fio`; ответ со словом `success` —
заявка принята. Коды номеров — со старого сайта (46849 Стандарт … 46854 Джуниор сюит двухуровневый).

Работает, когда сайт лежит на том же сервере, что и `remote.php` (hotel.yurla.ru). На другом хостинге
адрес задаётся атрибутом `data-endpoint` у формы в `tools/build.mjs`. Если отправка не удалась, гость видит
номер телефона отеля.

## Как поменять текст, цену или фото

1. Тексты и цены — `tools/content.mjs`, фото и подписи к ним — `tools/photos.json`.
2. Пересобрать страницы: `node tools/build.mjs` (Node 18+, без зависимостей).
3. Проверить в браузере: `npx serve .` или любой статический сервер.

Неразрывные пробелы после предлогов и в числах сборка ставит сама.
